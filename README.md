# Festive Wishes

A lightweight, shareable Diwali and New Year wishes website. Each link carries the sender, recipient, festival, and language in the URL, so the recipient can create and share their own wish without a backend.

## MVP flow

1. A sender creates a personalized wish link.
2. The recipient opens the link and sees the greeting addressed to them.
3. They click **Make a wish for someone**, which pre-fills their name as the next sender.
4. They generate a new link and continue the chain.

## Monetization path

The site includes a tasteful ad-slot placeholder. For production, add an approved ad network only after the site has original content, a privacy policy, and a clear consent flow where required.

## Deploy

This is a static HTML/CSS/JavaScript site and can be hosted on GitHub Pages from the `main` branch and repository root.
